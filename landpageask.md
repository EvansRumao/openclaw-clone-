# Ask Mode

## Question

what is the content in landing-page folder explain me in short

## Answer

The **landing-page** folder contains a simple, two-file static landing page:

**Files:**
- `index.html` — the page structure
- `styles.css` — the styling

**What it contains:**
- A **hero/header** section with navigation ("Nova" logo + Features/About/Contact links), a headline ("Build something amazing."), subtext, and a "Get Started" button.
- A **Features section** with three cards: Simple, Fast, Beautiful.
- An **About section** explaining it's built with just two files (HTML/CSS).
- A **Contact section** with a "Contact Us" button.

**Design:** Purple/blue gradient hero background, clean white feature cards, responsive grid, all styled with plain CSS (no frameworks or build tools).
